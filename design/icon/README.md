# Carthage app icon

The chosen design is **cothon-dark**: a light-grey "C" (the harbour ring of Carthage's cothon)
around a light-blue dot, on a dark slate tile.

- `carthage-icon.svg` — master artwork, 1024×1024 viewBox (tile inset 100 px with a soft shadow,
  macOS-style). Edit this one.
- `carthage-icon-1024.png` — 1024×1024 render of the SVG.

Palette: tile `#1C2127`, ring `#D5DCE3`, dot `#8FD0F5`.
